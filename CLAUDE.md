# Ponto de entrada para IA

Este repositório tem um único arquivo de instruções para agentes: **[AGENTS.md](AGENTS.md)**.

Leia o AGENTS.md inteiro antes de emitir qualquer comando. Ele traz a regra zero, que é perguntar ao
usuário qual dos seis caminhos ele quer antes de agir, as regras de segurança que valem para todos
os caminhos, e o roteiro de cada um.

A máquina onde tudo isto foi feito está descrita por inteiro em
[MAQUINA-REFERENCIA.md](MAQUINA-REFERENCIA.md). Use como exemplo trabalhado, nunca como valores para
copiar.

Não comece a trabalhar a partir deste arquivo nem do README. Vá para o AGENTS.md.
